# Mountain Resort

[Live Demo](https://elaborate-nougat-eb1668.netlify.app) 

Современный веб-сайт для горного курорта, разработанный на стеке React + Vite. Проект создан с упором на высокую производительность, чистую архитектуру и отличный пользовательский опыт.

## Ключевые особенности и оптимизации

### 1. Производительность и сборка
- **Оптимизация изображений:** Внедрена конвертация медиафайлов в современные форматы WebP и AVIF. Это позволило сократить вес изображений на 50–70% без потери качества.
- **Разделение кода (Code Splitting):** Реализована ленивая загрузка (React.lazy) для основных страниц. Главный JS-бандл уменьшен до ~95 kB (gzip), что обеспечивает мгновенную отрисовку интерфейса (FCP).
- **Анализ бандла:** Использован rollup-plugin-visualizer для мониторинга размера зависимостей и предотвращения раздувания проекта.

### 2. Архитектура и навигация
- **Маршрутизация:** Построена на базе react-router-dom с вложенными маршрутами и компонентом Layout для переиспользования хедера и футера.
- **Управление состоянием:** Локальное состояние компонентов управляется через хуки useState, что обеспечивает предсказуемость данных и простоту поддержки.

### 3. Стилизация и UI/UX
- **Tailwind CSS:** Утилитарный подход к верстке, обеспечивающий быструю разработку и полную адаптивность под любые экраны.
- **Обратная связь пользователю:** Реализованы компоненты загрузки (Suspense fallback) для плавного отображения контента при асинхронных переходах между страницами.

## Запуск проекта

Для локального запуска выполните следующие шаги:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/mountain-resort.git
   ```

2. Перейдите в папку проекта:
    ```bash
    cd mountain-resort
    ```
3. Установите зависимости:
    ```bash
    npm install
    ```

4. Запустите сервер разработки:
    ```bash
    npm run dev
    ```
## Структура проекта
